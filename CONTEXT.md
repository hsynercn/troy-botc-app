# Troy BotC domain glossary

- **Game night**: A scheduled Blood on the Clocktower event with a lifecycle of draft, published, completed, or cancelled.
- **Participation**: A player's relationship to one game night. RSVP is intent; attendance is a later organizer-confirmed outcome.
- **Attendance**: An explicit `ATTENDED` or `NO_SHOW` decision recorded by an organizer or admin. Only `ATTENDED` counts toward rank.
- **Rank**: Configurable participation progress based on distinct confirmed attended game nights, not game skill or RSVP volume.
- **Leaderboard**: Members ordered by attended game count descending, display name ascending, then player ID ascending.
- **Role**: Backend authorization level: `MEMBER`, `ORGANIZER`, or `ADMIN`.
- **Manual account**: An account created by an administrator for email-and-password sign-in; self-registration is not part of the member experience.
- **Google account**: An account created through Google sign-in for users who are not manually provisioned.
